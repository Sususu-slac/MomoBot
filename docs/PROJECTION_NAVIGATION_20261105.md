# Projection navigation — MomoBot 0.10.2

Projection requests used to clear the canvas before a 100 ms debounce and background read. Repeated slider events could therefore leave the entire display blank until dragging stopped. The viewer now retains the currently displayed image, caption, zoom and pan until the latest requested image has loaded successfully; pixel replacement is atomic. Different image dimensions trigger a fit. The loaded/requested identities remain distinct, so old images cannot provide a row or trial parameter for a newer request. Loading and read-error text explicitly identify retained images.

219 native Windows checks passed, including five additional navigation regressions. Tests cover a blocked read superseded by a later request, continuously dragging without an empty canvas, failed reads retaining the previous frame, parameter selection disabled for pending images, and fitting changed dimensions. A separate read-only GUI check dragged through 31 positions in an existing 601-projection HDF5, observed zero blank canvases, verified that the last displayed array matched the selected source frame, and retained zoom. No scientific compute job ran; source size/mtime remained unchanged. Local screenshots and evidence are excluded from public packages.
